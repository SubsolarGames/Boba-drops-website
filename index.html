Godot Topdown Shooter Template

What is it?

This template is a fully functional base project for a topdown pixel art shooter in Godot. It can be used as boilerplate for future projects. A lot of my games are topdown shooters; these games all share very comman characteristics that are tedious to remake every time.

Features

Player Character

Player character can move around, dash, take damage, and die

Shooting

Fully customizable guns that can be attached to the enemy or player. Guns have different stats such as bullet_speed, bullet_spread, or knockback

Enemies

Customizable enemies which have the ability to shoot, dash, and move to the player. They use a star pathfinding to move to the player in an intelligent way. They also can avoid obstacles such as explosives and each other.

Collectables

Different items such as coins and health pickups are fully function. Chests and guns can be interacted with and picked up. Enemies can also drop random loot.

Impact

Screenshake and hitstop are implemnted in a Global script which can be called anywhere. There is an Audio manager which is a Global script that can play different sounds using spacial audio.

Menus

Main menu, and settings menu are implemnted with buttons and sliders. Settings include: sfx, music, and screenshake sliders.

Code Structure

My project uses a combination of inheritence and composision.

Composision

Almost everything in the project is composed of smaller pieces. For example the player character is composed of these different nodes:

  • Healthbox
    • this component handles taking damage and killing the parent object
  • Moveable
    • this component is a character body and handles collision and velocity
  • Animated character
    • this component rotates the player based on velocity to add basic animations
  • Damagebox
    • this component deals damage to healthboxes
These components can be easily reused in another object, for example a rock.
  • Healthbox
  • Moveable
  • Lootable
    • this components randomly drops items from a list when the parent node dies

Inheritence

I also use inheritence in tandum with composision. For example the enemy parent node is build from different composite blocks. But then different enemies all inherite from the parent enemy. Parent Enemy

  • Healthbox
  • Moveable
  • Animated Character
  • Damagebox
  • Navigation Agent
    • Move to a target point (the player) and also avoid obstacles
An inherited enemy (enemy shooter)
  • All of parent features
  • Gun
    • Can shoot at a target point
  • shoot range
    • activates gun in a certain range
